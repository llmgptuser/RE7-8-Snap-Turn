Enable Snap turn in RE7/8

Install the latest version of Praydog's Reframework VR mod

Place `snap_turn_re8.lua` under `reframework\autorun` under your RE7/8 game dir.

Can change settings in "Snap Turn" under Script Generated UI.

Optionally, you can add re8_pivot_rotation_correction.lua as well. re8_pivot_rotation_correction.lua addresses the lateral movement of the world when turning the head from side to side due to game's camera rotation having a pivot instead of pure rotation. Note that this is not compatible with "Roomscale Movement". Disable "Roomscale Movement" under "Script Generate UI" before enabling "Pivot Rotation Correction".
